Overview of Audio Metadata Standards Ecosystem

This directory contains standard specifications, draft proposals, XML schemas, and working papers covering key AES audio metadata standards:

  • AES60-2011 & EBU Tech 3293 (EBUCore): Core audio metadata vocabulary, schema structure, and Dublin Core extensions.
  • AES31 (Parts 1 - 4): File & disk format transport, Broadcast Wave Format (BWF), Simple Project Exchange (ADL), and XML ADL specifications.
  • AES41 (Parts 1 - 5): In-band audio-embedded metadata in PCM sample streams (recoding decisions, MPEG Layer II, AAC, Dolby E, Loudness/True-Peak/Downmix).
  • AES-X098C & iXML: Administrative processing history, preservation signal graphs, and location sound recording payloads.
  • AES-X230: Transducer microphone profile object lists.
