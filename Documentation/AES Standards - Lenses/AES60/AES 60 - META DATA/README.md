## Key Standard Categories & Functional Breakdown

### 1. AES60 & Core Audio Metadata
* **AES60-2011**: Core audio metadata schema defining descriptive, administrative, and technical metadata attributes aligned with Dublin Core and EBUCore (EBU Tech 3293).
* **EBU Tech 3293 v1.8**: Comprehensive reference specification for EBU Core metadata set.
* **ExtendAES60.pdf**: Technical guidelines on extending AES60/EBUCore XML schemas for domain-specific requirements.

### 2. AES31 (Audio Interchange & Edit Decision Lists)
* **AES31-1**: File and disk structure rules for DAW session data exchange.
* **AES31-2**: Broadcast Wave Format (BWF) file structure for multi-channel audio data transport.
* **AES31-3 & AES31-4**: Simple Project Exchange and XML Implementation of Audio Decision Lists (ADL).

### 3. AES41 (Audio-Embedded Metadata / In-Band Metadata)
* **AES41-1 to 5**: Specifications for embedding metadata directly within audio sample bits (PCM LSBs) for recoding decision data, Dolby E, MPEG Layer II, AAC/HE-AAC, and EBU loudness/true-peak/downmix parameters.

### 4. Preservation & Technical History (AES-X098C & iXML)
* **AES-X098C**: Processing and handling history of audio objects (signal graph, preservation actions, processing events).
* **iXML Schema**: Metadata payload embedded in broadcast WAV headers for location sound recording (scene, take, track names, sync points).
* **AES-X230**: Microphone Profile object list definition for transducer metadata.
