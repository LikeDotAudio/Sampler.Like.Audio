AES standard for metadata –

Processing and handling history

of audio objects

Abstract

This standard provides a vocabulary to be used in describing structural and administrative metadata about the processing and handling history of audio objects during audio preservation activities. Some implementations also refer to this metadata as technical metadata. The characteristics of the processing and handling of audio objects captured by this standard may be of use to audio communities beyond the audio preservation community.

Foreword

This foreword is not part of the AESxx-xxxx AES standard for metadata – Processing and handling history of audio objects.

Work on this project began in earnest in 2002 following a series of meetings that the chair attended at the Library of Congress in which the subject of technical metadata requirements for audio were discussed. Since that time, Harvard University developed a working proof of concept of the metadata schema herein described, which was shared with Indiana University as a part of the National Endowement for the Humanities funded Sound Directions research project. During that project, IU developed theirits own prototype tools that implemented that earlier draft of the schema. This version retains all of the earlier functional requirements of the earlier draft while offering a somewhat simplified implementation.

Introduction

This standard sets out the vocabulary to be used in describing the processing and handling history of audio objects in audio preservation work. This metadata, sometimes referred to as ‘process history’, 'digital provenance' (or ‘digi-prov’), describes the details of how audio objects are treated and/or migrated. Essentially it provides the ‘who’, ‘where’, ‘what’, 'when' and ‘how’ information that clarifies the provenance of the audio object with regard to the work that has been done to restore and/or preserve the object. This vocabulary is expressed in the form of an Extensible Markup Language (XML) schema. By doing so it provides a structured human readable instance document that can be easily parsed and manipulated using any of a number of freely available programming libraries and tools.

1 Scope

This standard concerns the technical documentation of the processing and handling of audio files and physical audio formats carried out during audio preservation and restoration work. This documentation, here referred to as metadata, provides a description of where the work occurred, who did the work, when the work was completed, and how the work was done, including a full description of the audio signal chain as it was configured during the processing.

3 Definitions and abbreviations

3.1 Audio object

A general term used to describe physical audio carriers, and digital audio in the form of files and streams.

For the purposes of this document, the term physical audio carriers shall be understood to mean only those carriers to which an audio data essence is intrinsically bound to the physical object. For example, an audio DAT tape is a physical digital audio object. Wave files on the other hand are file based digital audio objects. They can be moved, copied, and renamed without the need to play the audio essence. In the latter case, the file exists on a storage device, but it is not intrinsically bound to that device. Therefore there is no need to describe the physical storage given its transient nature.

For additional details see AES57-2011, AES standard for audio metadata – Audio object structures for preservation and restoration.
